# 工具与约定

## 接口清单怎么更新

官网已经下线 `openapi.json` 和 `aidocs/llms-full.txt`。现在以商城 + 单接口 Markdown 为准：

- 目录：https://apizero.cn/sitemap.xml 的 `/marketplace/{slug}`
- 详情：https://apizero.cn/aidocs/{slug}/raw.md
- 入口索引：https://apizero.cn/llms.txt
- 人工核对：https://apizero.cn/marketplace

重新导出：

```bash
python3 scripts/export_interfaces.py
```

产物：

- `data/apis.json` / `data/apis.csv`
- `docs/api-inventory.md` / `docs/api-details.md` / `docs/api-growth-priority.md`
- `LLMS.md`

原始 Markdown 会缓存到 `data/cache/raw/`，不要提交。

## 推 GitHub

这个仓库的远程是 `https://github.com/MageGojo/apizero-examples`。用户说「更新到 GitHub」= `git push origin main`，不是部署官网。
